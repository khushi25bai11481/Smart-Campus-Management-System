# Smart Campus Management System

A Java-based command-line application for managing students, courses, complaints, attendance, and campus facilities.

## Project Description

The Smart Campus Management System is designed to provide a simple and organized way to manage important campus activities using Java.

The system uses a menu-driven interface and follows an object-oriented programming approach.

## Features

1. Student Management
   - Add student
   - Display student details
   - Search student

2. Course Management
   - Add course
   - Display course details
   - Search course

3. Complaint Management
   - Register complaint
   - Search complaint
   - Update complaint status
   - Display complaints

4. Attendance Management
   - Add attendance record
   - Display attendance
   - Search attendance

5. Facility Management
   - Add campus facility
   - Display facilities
   - Search facility

6. Exit
   - Exit the application safely

## Technologies Used

- Java
- Object-Oriented Programming
- ArrayList
- Command-Line Interface
- Git and GitHub
